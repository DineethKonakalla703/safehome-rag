# Priority 1 Scope

## Included

- Demo role selection for four users
- Client-side route protection and navigation by role
- Main Admin, Block A Admin, and Resident dashboards
- Complaint creation and deterministic analysis
- Ticket access scoped by community role
- Technician assignment and status updates by administrators
- Bill generation, billing lists, and updated dashboard totals
- Mock seed data and localStorage persistence

## Not included

- Backend server or REST API
- MongoDB Atlas, PostgreSQL, or any database
- Real authentication or production security
- Real AI, RAG, GraphRAG, or external model calls
- Real photo upload, notifications, or payment processing
- The remaining modules envisioned for the full system

## Demo goal

Prove that one high-risk resident complaint can move visibly from creation and classification through block administration, technician assignment, status change, billing, and dashboard reporting.
